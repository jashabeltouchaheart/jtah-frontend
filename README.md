# JTAH Foundation

## Structure

```
jtah-frontend/   Next.js 14 · TypeScript · Tailwind · GSAP · Lenis
jtah-studio/     Sanity Studio v3
```

## Environment setup



### jtah-frontend

```bash
cd jtah-frontend
cp .env.example .env.local
# Fill in YOUR JTAH values from sanity.io/manage
npm install
npm run dev
```



### jtah-studio

```bash
cd jtah-studio
cp .env.example .env.local
# Fill in YOUR JTAH values from sanity.io/manage
npm install
npm run dev   # opens Studio at localhost:3333
```
